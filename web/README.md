# web

브라우저에서 동작하는 프론트엔드 영역입니다.

- HTML
- CSS
- JavaScript
- 게임 화면 및 사용자 인터랙션

이 디렉터리는 클라이언트 측 로직과 UI를 관리합니다.

## 프론트엔드 기본 규칙

- 브라우저에서 바로 보이는 화면을 담당한다.
- HTML은 구조, CSS는 스타일, JavaScript는 동작을 담당한다.
- 데이터가 필요하면 `fetch()`를 사용해 서버 API를 호출한다.
- 직접 DB에 접근하지 않는다.
- `index.html`은 기본 진입점이며, 다른 페이지가 생기면 그 페이지도 여기에 추가할 수 있다.

## 현재 구조 예시

```text
web/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## 실제 동작 흐름

```text
사용자 클릭
  → JavaScript 이벤트 발생
  → fetch('http://localhost:8000/api/...')
  → Python 서버 응답 JSON
  → 화면 렌더링
```

> 이 프로젝트에서 프론트는 "보여주는 역할"에 집중하고, 실제 데이터는 백엔드가 제공한다.

## 초보자 팁

- CSS/JS를 한 파일에 넣는 건 작은 프로젝트에서 편할 수 있지만, 프로젝트가 커지면 관리가 어려워진다.
- `script.js`는 화면 로직만 다루고, 게임 로직 자체는 `games/`와 서버 쪽으로 분리하는 게 좋다.
- 화면 확인용 더미데이터는 개발 중에만 쓰고, 나중에는 API로 대체해야 한다.
