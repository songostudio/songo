# api

Python 기반 서버 및 백엔드 로직을 보관하는 영역입니다.

- 데이터 처리
- AI 연동
- API 서비스
- 서버 로직

브라우저 외부에서 수행해야 하는 작업을 관리합니다.

## 백엔드 기본 규칙

- 화면을 직접 그리지 않는다.
- 데이터를 JSON 형태로 내려준다.
- 프론트가 요청하는 API 엔드포인트를 제공한다.
- 브라우저는 서버와 통신할 때만 접근할 수 있고, DB나 로직은 서버에서 처리한다.

## 현재 예시 API

```text
GET /api/games/company-battle
```

이 엔드포인트는 다음 정보를 JSON으로 응답한다.

- 게임 제목
- 설명
- 두 개의 기업 데이터
- 각 기업의 매출/직원 수
- 승자 정보

```json
{
  "title": "기업 배틀",
  "description": "매출과 직원 수를 기준으로 더 큰 기업을 고르는 간단한 게임",
  "companies": [
    { "name": "넥슨", "revenue": 4.0, "employees": 7700 },
    { "name": "크래프톤", "revenue": 2.4, "employees": 1900 }
  ]
}
```

## 로컬 실행 흐름

```bash
cd songo
python3 api/server.py
```

그다음 브라우저에서 아래 주소를 확인한다.

```text
http://localhost:8000
http://localhost:8000/api/games/company-battle
```

> 실제 서비스에서는 이 API가 DB, AI, 사용자 저장 정보를 기반으로 응답하게 된다. 지금은 개발을 위해 더미 데이터로 먼저 연결해본다.

## 초보자 팁

- `api/`는 서버 로직을 넣는 폴더다. 화면 코드는 여기 넣지 않는다.
- API 응답 형식은 프론트와 미리 맞춰야 한다.
- 더미데이터로 연결을 테스트하는 건 정상이고, 실제 출시 전에는 데이터 소스와 스키마를 정리해야 한다.
