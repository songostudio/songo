# games

게임 관련 콘텐츠와 로직을 관리하는 영역입니다.

- 게임 규칙
- 스테이지/레벨 구조
- 게임 전용 모듈
- 로직 및 데이터

이 디렉터리는 실제 게임 구현이 확장될 때 사용합니다.

## 게임 영역의 역할

- 프론트엔드에서 보이는 화면과는 별개로, 게임 규칙을 정리한다.
- 현재는 작은 게임 로직을 테스트하고, 나중에 이 영역을 확장해 여러 게임을 관리한다.
- 화면 UI와 게임 로직은 분리하는 게 좋다.

## 예시 구조

```text
games/
├── company-battle/
│   ├── rules.py
│   ├── data.py
│   └── README.md
└── README.md
```

## 기본 원칙

- 게임 규칙은 상태와 점수를 기준으로 정의한다.
- 규칙이 바뀌면 화면 로직도 함께 수정되므로 둘을 분리해 관리하는 게 편하다.
- 같은 게임이 여러 번 실행될 수 있으므로, 데이터와 로직을 재사용 가능한 형태로 설계한다.

## 초보자 팁

- 아직은 한 두 게임에 집중하자.
- 한 번에 여러 게임을 확장하려고 하지 말고, 먼저 기업 배틀처럼 가장 단순한 형태를 완성하는 게 중요하다.
- 화면은 `web/`, 백엔드 응답은 `api/`, 게임 규칙은 `games/`로 나누면 책임이 분명해진다.
